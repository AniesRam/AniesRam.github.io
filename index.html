Final year project

MediCare: matching symptoms to likely diseases

A hospital web app where patients tick the symptoms they have and a Random Forest model suggests what it might be, with a confidence score and a nudge to book a doctor. Doctors see the prediction during consultations and can accept or override it. Those corrections are logged so the model can be retrained.

I built the whole thing in Flask with PostgreSQL and SQLAlchemy. There are separate logins for patients, doctors and admins, plus appointments, a queue system, a floor map and a Power BI report for admins.

Python · Flask · PostgreSQL · SQLAlchemy · scikit-learn · Power BI

      Request ticketing with Power Automate

      Requests were being tracked by hand, which was slow and easy to lose track of. I made a Microsoft Form that gives each request an ID, logs it to a master sheet, sorts it into one of 4 category sheets and pings the right people on Teams.     • UMS
      Text analytics

      How people talked about vaccination campaigns

      Sentiment analysis on social media posts about vaccination. Most of the work was cleaning: tokenising, removing stop words and lemmatising. Then I trained multi-class classifiers on TF-IDF features to compare positive, neutral and negative sentiment.

      Python · NLTK · scikit-learn · GitHub (opens in a new tab)

    • UMS
      Coursework

      Fine-tuning DeBERTa on movie reviews

      A class assignment: fine-tune microsoft/deberta-v3-base on the SST-2 movie review dataset to tell positive reviews from negative ones. I trained it for 3 epochs with Hugging Face's Trainer, wrote a small function to run it on new sentences and presented it to the class.

      PyTorch · Hugging Face Transformers · Datasets

    • Personal
      Built solo

      A pet feeder that tells you when it's empty

      Built from scratch on an ESP8266. A real-time clock opens a servo at 10am, 2pm and 8pm to drop food. An ultrasonic sensor at the top measures how much is left, and a red LED comes on when it runs low. It also hosts a tiny web page on the home Wi-Fi so you can check on it from your phone.

      ESP8266 · Arduino C++ · HC-SR04 · DS3231 RTC · servo
